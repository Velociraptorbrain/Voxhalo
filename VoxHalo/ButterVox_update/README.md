# Butter Vox (macOS)

Vocal chain + melting echo plug-in (Audio Unit, VST3, Standalone) built with JUCE.

Chain: Input, Low Cut, De-Ess, Squash (compressor), Toast (drive), Air, Echo (sync, tap tempo, ping-pong, modulation, filtered feedback), Melt reverb with Glitter shimmer, Mix, Output.

## Make the installer on GitHub
Push or upload to GitHub. The workflow in `.github/workflows/build-mac.yml` builds on a Mac runner and uploads the `.pkg` and `.dmg` as a downloadable artifact (Actions tab, open the latest run, scroll to Artifacts).

## Build on a Mac
Install Xcode, CMake and Git, then run `./build_mac.sh`. Installers appear in `dist/`.

## Layout
- `Source/Params.h` every parameter, range, default and tooltip
- `Source/Presets.h` generated from `tools/presets_data.py` (edit there, run `python3 tools/gen_presets_header.py`)
- `Source/Layout.h` and `assets/skin_bg.png` generated by `python3 tools/build_skin.py` (interface artwork and control positions)
- `tools/make_icons.py`, `tools/make_manual.py` regenerate the icons and the PDF manual
