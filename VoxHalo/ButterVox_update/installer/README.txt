build_mac.sh creates dist/ButterVox-1.0.0.pkg (installer) and dist/ButterVox-1.0.0.dmg.
The installer places:
  Butter Vox.vst3        -> /Library/Audio/Plug-Ins/VST3
  Butter Vox.component   -> /Library/Audio/Plug-Ins/Components   (Audio Unit, used by Logic Pro and GarageBand)
  Butter Vox.app         -> /Applications
  User manual PDF        -> /Library/Application Support/Butter Vox
