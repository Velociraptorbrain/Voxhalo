build_mac.sh creates dist/VoxHalo-1.0.0.pkg (installer) and dist/VoxHalo-1.0.0.dmg.
The installer places:
  VoxHalo.vst3       -> /Library/Audio/Plug-Ins/VST3
  VoxHalo.component  -> /Library/Audio/Plug-Ins/Components   (Audio Unit, used by Logic Pro and GarageBand)
  VoxHalo.app        -> /Applications
  User manual PDF    -> /Library/Application Support/VoxHalo
